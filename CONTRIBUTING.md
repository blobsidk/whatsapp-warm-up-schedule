# Contributing

Corrections and updates are welcome. Open an issue or a pull request.

## Useful contributions

- A WhatsApp or Meta page changed, moved or was added. Include the link and the date you checked it.
- A number or rule here is wrong or unclear.
- A better plain-language template, or a translation of the templates.

## Rules

1. **Cite WhatsApp for anything about WhatsApp.** Link the official page (faq.whatsapp.com, whatsapp.com or developers.facebook.com) and add the date you checked it. Press reports must say they are press reports.
2. **Label recommendations.** If WhatsApp does not publish it, call it a recommendation.
3. **No guarantees.** Never say a plan, tool or setting prevents bans.
4. **No promotion.** No product links, affiliate links or vendor comparisons. The maintainer disclosure in the README is the only exception.
5. **Keep the files in sync.** A change to the schedule must update the CSV files, the JSON file and the README tables together.
6. **Write plainly.** Short sentences. No em dashes. No marketing language.
